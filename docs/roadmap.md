# ロードマップ
## 初回リリース
初回リリースにおいては、以下の機能を実装した最低限のバージョンとする。

- 対応音源データはwavのみとする
- 音源データストレージ実装は、ファイルシステム上の音源データファイルを読み取り専用で扱うものとする
- メタデータ・検索インデックス実装はインメモリとする
- メタデータ・検索インデックス実装は起動時のみに行う
- ユーザーは検索機能を伴わないリリース一覧画面をサムネイル形式で閲覧することができる
- リリース一覧画面ではスクロールしていくと自動的に次のリリース群が読み込まれていく
- ユーザーはサムネイルをクリックすることで、対応するリリースの詳細画面に遷移することができる
- リリースの詳細画面では、リリースに含まれる楽曲の一覧をリストで閲覧することができ、クリックすることで再生画面に遷移することができる
- 楽曲の再生画面では、楽曲の再生・一時停止・シークが可能である
