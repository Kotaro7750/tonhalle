# ドキュメントのスコープ
本ドキュメントは以下をスコープとする。

- バックエンドAPIサーバーで用いるソフトウェア技術スタック
- 利用ソフトウェア技術スタックのバージョンの考え方

ただし、このドキュメントは利用するライブラリ全てをスコープとするのではない。
それだとパッケージマネージャーのマニフェストの劣化となるためである。
代わりに、核となる主要な技術スタックについてのみをスコープとする。

そのため、このドキュメントに記載されていないライブラリを使用することは許容する。

# ソフトウェア技術スタック
## プログラミング言語
型安全性・性能・書きやすさを考慮して、Rustを使用する。

## サーバーフレームワーク
非同期ランタイムとしてRustにおけるデファクトスタンダードとなっているtokioのコミュニティが作成している[axum](https://docs.rs/axum/latest/axum/)を使用する。

## OpenAPI利用
OpenAPIのドキュメントを仕様の正本とするため、[openapi-generator](https://openapi-generator.tech/docs/generators/rust-axum)を利用してコードを生成する。

生成したコードはGitの管理対象に含めることとする。

## 音源データのメタデータ
音源データのメタデータの取り扱いは、自前で解析処理を実装するのではなく、[lofty](https://docs.rs/lofty/latest/lofty/)を利用する。

# バージョンの考え方
ソフトウェア技術スタックのバージョンは、安定性と最新性のバランスを考慮し、制約のない限りは最新の安定版を使用する。

ただし、利用時点でまだ安定版が存在していない場合や、安定版ではないものの成熟していると思われる場合には、必ずしも安定版にこだわる必要はない。
