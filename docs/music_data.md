# ドキュメントのスコープ
本ドキュメントは以下をスコープとする。

- 対応する音源データフォーマット
- メタデータの取得元
- 音源データの取り込みと検証

# 対応する音源データフォーマット
対応する音源データのフォーマットとしては以下とする。

- WAV
- MP3
- AAC
- FLAC
- OGG

なお、これ以外のフォーマットの音源ファイルであっても明確に拒否するわけではなく、外部ライブラリによるサポートなどで再生できる可能性があるがあくまでもベストエフォートである。

# メタデータの取得元
[domain.md](./domain.md)に記載しているようなメタデータについては、音源データに付与されているもののみを取得元とする。

# 取り込みと検証
## リリース単位の検証
音源の取り込みはRelease単位で行い、Releaseに所属する全ての音源に対して[domain.md](./domain.md)に定義するドメインモデル制約の検証を行った結果有効だった場合のみそのReleaseを取り扱う。

各音源のRelease用メタデータから導出したReleaseIdは、ストレージから取得した所属Releaseの識別子と一致しなければならない。
また、Releaseに所属する全ての音源から取得したRelease用メタデータは、全て一致しなければならない。

一つでも無効な音源があった場合にはそのRelease全体の取り扱いを行わない。

## 重複の取り扱い
同じRelease内で同じTrackIdのオリジナル音源が複数見つかった場合は、ストレージの列挙順で最初のものを採用する。
後続の音源は警告を出してインデックス登録から除外し、元の音源ファイルは保持する。

異なるRelease間に同じTrackIdが存在する場合は、リリース間の整合性検証でエラーとする。
