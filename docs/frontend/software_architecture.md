# ドキュメントのスコープ
本ドキュメントは以下をスコープとする。

- フロントエンドSPAにおける責務分割の設計方針
- 各責務について主に責務を担うライブラリについて

# 責務分割
## 状態管理
SPA内部における状態管理は、[Zustand](https://zustand-demo.pmnd.rs/)を用いて行う。
バージョンは最新のv5系列を使用する。

## データ取得
バックエンドAPIとの通信は、API仕様書に基づいた自動コード生成されたクライアントコードを使用する。

また、サーバー状態管理は[TanStack Query](https://tanstack.com/query/latest)を用いて行う。
バージョンは最新のv5系列を使用する。
