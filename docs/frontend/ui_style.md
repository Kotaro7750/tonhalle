# ドキュメントのスコープ
本ドキュメントは以下をスコープとする。

- フロントエンドSPAが目指すUIの方向性
- 情報の表示と操作体験に関する判断の基準

コンポーネントの構成やスタイルの実装方針は[ui_development.md](./ui_development.md)で定義する。

# 目指すUI
見た目の簡潔さと、レスポンシブで直感的に操作を行える使いやすさの高いUIを目指す。

また、ネイティブアプリのような操作体験を提供することを目指す。

# 情報の表示
## 基本方針
アイコンによる表示と文字による表示のどちらも可能である場合には、アイコンのみの表示としシンプルさを保つ。
文字による表示は、アイコンによる表示では意味が伝わりにくい場合に用いる。

## 文字
文字はソリッドで読みやすい印象を基本とし、基本的な表示言語は英語とする。

ただしこれは、音源のタイトルやアーティスト名などのメタデータの表記を変更することを意味せず、メタデータは元の表記を尊重する。
また、必要に応じて追加するツールチップ中の言語は日本語とする。

つまり、シンプルさ・見た目の統一性を保つために英語は採用するものの、使用ユーザーは日本語話者であることを前提とする。

## レスポンシブ対応
どのデバイスで利用するかという前提をおかず、幅広い種類のデバイスにおいて使いやすいレイアウトを維持する。

## アクセシビリティ
キーボードで操作することも前提にするが、ネイティブアプリ同様の操作体験を提供するため、フォーカスが残るようなUIは避ける。

# 操作体験
全ての操作は直感的に、統一感のある方法で行える必要がある。
